# 三维凸包场景

打开 `Assets/Scenes/ConvexHull3DDemo.unity` 并进入 Play Mode。初始点集包含立方体的 8 个顶点和 4 个内部点。此场景独立于二维场景，提供增量法、QuickHull、礼品包装法、分治归并法四种独立教学演示。

## 操作

- 按住右键移动鼠标转向；同时用 W/S 前后、A/D 左右、Q/E 下上移动。方向相对于相机，光标始终可见。松开右键或窗口失焦停止漫游。
- 左键单击小球选择，空白取消选择。蓝色为凸包顶点，灰色为内部点，橙色为选中点。
- 拖动红 X、绿 Y、蓝 Z 轴线或箭头，只改变对应世界坐标。几乎正对相机的轴变灰且不可拖动；换个观察方向即可恢复。拖轴期间相机不移动。
- Delete 删除选中点。输入框取得焦点时，Delete 交给输入框处理。
- “增加点”在相机前方默认 8 世界单位处创建并选中点。
- 随机数量接受 1–1000 的整数，默认 20。“随机生成”替换原点集，在当前视野前方深度 6–14 内生成，避开工具栏和屏幕边缘，不移动相机。无效输入保留原点集。
- 可以逐个删除到空集。重复坐标节点独立存在并可编辑；重叠时优先选择已选节点，否则选择最后创建节点。


## 三维算法演示

顶部选择“增量法 / QuickHull / 礼品包装法 / 分治归并法”，再点击“播放演示”。底部面板仅保留暂停/继续、下一步、停止和 0.25×–4× 速度选择。在 VisualAlgo 中 Escape 打开场景暂停菜单，冻结相机和演示；返回游戏后保留原演示状态。停止演示请使用下方“停止”按钮。空点集不能播放。

- **相机完全由玩家控制**：开始、切换步骤、暂停、完成、停止均不定位或缩放相机，不改变 FOV，不调整全局时间倍率。播放和暂停期间仍可按右键转向并用 WASD/QE 漫游；未制作绕目标观察或自动聚焦。
- 演示复制点集快照。播放期间锁定新增、删除、随机替换、选择与轴向拖动，控制器接口也拒绝点集修改；正常凸包表面、选择轴和原始顶点配色暂时隐藏。实时算法、统计、点 ID 和坐标不受演示计算影响。
- 暂停冻结教学计算、计时和面片/边线过渡。下一步推进一个可见教学事件，完成过渡后仍暂停。完成后短暂停留，再清除教学覆盖层并恢复正常显示；若暂停在完成状态，继续或停止可退出。
- 颜色：橙色表示检查对象/候选平面，红色表示待移除面，黄色表示轮廓或包装边，绿色表示暂时最远点/待加入面，蓝色表示当前已接受边界。增量法中的“当前边界”不保证属于最终答案。
- 活动辅助线、轮廓和点外圈默认可透过遮挡显示；`HullTeachingOverlay3D.Xray Assistance` 可在 Inspector 关闭。新面淡入、连接边延伸；点本身不移动。
- 点编号每次播放重新生成，只覆盖不同坐标，重复坐标保留最早节点作为代表。编号在本次演示期间稳定；超过 80 个不同坐标时只标注当前比较点和候选点，避免满屏文字。

**增量法**：初始四面体 → 按快照顺序插入点 → 逐面判断点在哪一侧 → 标记可见面 → 提取轮廓边 → 预览新面 → 提交替换。内部点会展示拒绝步骤。“可见”以待插入点为观察点，与玩家相机无关。

**QuickHull**：初始四面体 → 分配面外点 → 完整遍历当前面的外点集合并比较垂距 → 确认最远点 → 可见面/轮廓扩张 → 重新分配受影响外点。遇到暂时最远点不会跳过后续候选；辅助线连接点与平面垂足；垂足位于面域外时，再用虚线连接垂足与最近面边界，不显示面法线。

**礼品包装法**：寻找起始支撑边 → 沿待处理边扫描候选点与平面 → 确认所有点位于平面内侧 → 收集该平面的共面点并提取面域边界 → 加入一个支撑面 → 沿未闭合边继续包装，直至外壳闭合。真实判断使用双精度侧别谓词，不依赖角度排序；没有调用实时 QuickHull 生成演示答案。

教学会话按需生成事件，不预存全部比较。`HullPlayback3D` 可配置步骤间隔（默认 0.6 秒）、过渡时间（默认 0.2 秒）和每次计算推进预算（默认 4096）。建议教学样例使用 12–30 点；大规模数据仍逐一执行比较，播放可能很长，可随时调速或停止。

计算实现位于 `TeachingGeometry3D.cs` 和 `HullTeachingSession3D.cs`；渲染、播放状态和 UI 分别由 `HullTeachingOverlay3D`、`HullPlayback3D`、`HullPlaybackPanel3D` 管理。共用几何谓词和拓扑动画，三种求解流程独立于正常状态下的 `ConvexHull3D.Compute`。

## Inspector 配置

选择场景中的 `Convex Hull 3D Demo`：

- `Point Diameter`：小球直径，默认 0.3 世界单位。
- `Edge Width`、`Face Color` 的 Alpha、各节点颜色：线宽、表面透明度、普通/凸包/选中颜色。
- `Hit Radius`、`Axis Length`、`Axis Width`、`Axis Hit Radius`：世界单位的拾取与操作轴尺寸。
- `Move Speed`、`Look Sensitivity`、`Add Distance`、`Random Near/Far`：相机移动和点生成参数。
- `Initial Points`：启动点集。`Relative Tolerance` 默认 1e-7。

UI 使用已有 UIFramework、GenSenRounded 字体、1280×720 参考分辨率与 Expand 等比缩放，以及独立 URP Overlay UI 相机。节点和操作轴不按像素调整世界尺寸；透视下会随距离正常缩小。箭头 Mesh 已制作，无需提供外部素材。

## 计算与渲染

`ConvexHullDemo3D.ConvexHull3D.Compute(IReadOnlyList<Vector3>, double tolerance = 1e-7)` 不修改输入，返回：

- `Dimension`：Empty / Point / Segment / Planar / Volume。
- `Vertices`：去重后的几何极点。
- `SourceIndices`：每个返回顶点对应的原输入索引；精确重复坐标取首次出现者。
- `Triangles`：索引 `Vertices` 的三角形；三维面朝外，共面结果在渲染时双面显示。

内部使用双精度、居中与尺度归一化的 QuickHull：初始四面体、面外点集合、删除可见面、提取轮廓边并扩展。结束时合并共面面域，去除共线中间顶点，再三角化，因此面内部和边中间的点不计入凸包顶点数。空、单点、共线、共面数据有独立退化处理。

控制器使用稳定 ID 标识节点，在 LateUpdate 汇总修改，每帧最多重算一次。相机移动与选中变化不触发重算。小球对象、工作容器、渲染 Mesh 复用；不逐面创建 GameObject。每次求解会产生新的结果数组，不能把对象池复用理解为完全零分配。

三角形采用平面法线，先透明背面后正面绘制、开启深度测试；线条在 Shader 中按世界距离绘制，包括三角化内部边。表面没有拾取碰撞体。

## 制作及验证

- `AgentScripts/BuildHull3D.cs`：编辑器资源制作脚本；保护未保存场景，拒绝覆盖已存在的正式场景。
- `AgentScripts/VerifyHull3D.cs` / `VerifyHull3D.Algorithm`：131 组、5,482,204 项几何检查，通过。覆盖退化、精确重复、面/边附加点、内部点、反向输入、远离原点、近共面、随机数据及 1000 个球面点；核对包含关系、面朝向、无零面积面、闭合边、Euler 关系和已知体积。
- `AgentScripts/VerifyHull3DInteraction.cs` / `VerifyHull3DInteraction.Run`：轴向位移、不跳变、正对轴保护、重叠选择、随机数量和范围、非法输入、UI 事件、对象与 Mesh 复用及重算频率检查。
- `AgentScripts/VerifyHull3DLiveInput.cs` / `VerifyHull3DLiveInput.Begin`：非阻塞真实帧输入测试。结果读 `SessionState.GetString("Hull3DLiveResult", "missing")`；不要在进行中的验证期间退出 Play Mode。宽屏 2560×1440、窄屏 800×900 均通过 Delete、增加点、随机、输入框隔离、右键与 W 移动、松开停止测试。
- 本机编辑器实测：1000 个随机点连续 50 次修改，QuickHull 平均约 1.12 ms，最大约 1.38 ms，测试窗口内第 0 代 GC 次数为 0。数值只代表本次随机数据与机器，不能作为所有点集的耗时上限。

通过 unity-pipeline 编译与 Play Mode 验证；未构建 Player，未修改二维场景或框架示例。

## 分治归并演示

在顶部选择“分治归并法”。此算法独立计算，不调用实时 QuickHull 或重新求左右点集的整体凸包。按 X/Y/Z 排序生成本次编号；沿相邻不同 X 值之间、最接近中位数的位置分割。同 X 点不强行拆组。每组最多四点或整组退化时，直接显示基本子凸包。

流程为左子组、右子组、父归并。显示左右分组颜色；先观察二维投影轮廓，再展示跨组支撑边，沿端点邻接顶点寻找支撑面。比较时保留旧候选面，越界才绕固定边旋转辅助面；新桥接面逐个加入。面带闭合后，内部旧面变红并一次性移除，保留面直接转为父组颜色。最终统一为蓝色。演示不显示文字描述，保留点编号；底部仍只有三个按钮和速度下拉框。不显示分隔面，投影轮廓落在可见的半透明网格承载平面上。

场景控制器同物体上的 `HullPlayback3D.Merge Hull Detail` 默认“关键步骤”，可在 Inspector 改为“详细步骤”。前者显示有效更新及每次搜索至少一次否决（若存在），后者显示所有邻接候选比较；两者结果相同。播放开始后设置锁定到本次会话。叶子内部点变暗、非活动分支弱化，不移动原始点，也不移动相机。

会话公开 `NeighborComparisons`、`ValidationComparisons` 和 `VisibleSteps`，分别记录邻接侧别判断、支撑面/旧面有效性验证及可见动画步数。归并包含对子凸包极点的完整验证和投影排序，本版不声称达到经典优化实现的 O(n log n)。1000 极点可计算但动画较长，可暂停、调速或停止。

资源制作：基础 `BuildTeaching3D` 之后运行 `BuildMergeTeaching3D.Run`，后者更新四选项下拉框、投影承载平面，不重建场景、不保存用户其他未保存修改。

验证：`VerifyMergeTeaching3D.Run` 对关键/详细模式进行几何对照，包括两平面子凸包、点/线段与体积合并、同 X 分组、共面桥接、1000 随机点及 1000 球面极点。`VerifyMergePlayback3D.Run` 验证阶段顺序、暂停、单步、停止重播与原始数据/相机不变；`VerifyMergeTeaching3DUI.Begin` 进行四算法真实输入测试。

本轮分治验证结果：120 组关键/详细模式测试、5,629,950 项几何检查、456,679 个可见事件；四算法完整播放回归 134 项检查。2560×1440 与 800×900 的真实输入测试各 104 项通过。最后复测未出现新增功能相关 Console 错误，未构建 Player。
